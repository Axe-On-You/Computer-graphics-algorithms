# АКГ · Лабораторная работа 2

**Тема:** расчет яркости сферы от двух точечных источников света.  
**Авторы:** Михайлов Петр Сергеевич, Гришин Артем Евгеньевич. Группа АКГ 1.2.  
**Преподаватель:** доцент Потемин Игорь Станиславович.

Перспективное изображение сферы, ламбертовские источники, отражение Блинна–Фонга. Реализовано дополнительное задание: независимые направления и произвольные положения ламп, включая отрицательные Z и расположение под наблюдателем или сферой.

## Запуск

Python 3.10+ с Tkinter. В PyCharm открыть папку и выбрать интерпретатор.

```bash
python -m pip install -r requirements.txt
python AKG_2.py
```

Для каждой лампы задаются положение и точка прицеливания. Кнопка «Направить в центр сферы» устанавливает цель в текущий центр. «Исходные параметры» восстанавливает весь первоначальный расчет. Сверху есть список пяти готовых примеров. После ручного редактирования полей нажать «Рассчитать».

Лампы внутри/на непрозрачной сфере допустимы, но не освещают внешнюю поверхность. В примере «Под сферой» верхняя видимая сторона темная — это ожидаемый результат. Координаты P относятся к поверхности, S — к экрану, где стоят маркеры.

## Воспроизведение

```bash
python AKG_2.py --export results
python AKG_2.py --scene scenes/under_observer.json
python AKG_2.py --scene scenes/below_sphere.json --export results/below_sphere
python verify.py
```

При экспорте сохраняются PNG, контрольные значения CSV и полные параметры `scene.json`. В Windows Tkinter обычно входит в установку Python; в Ubuntu при его отсутствии нужен пакет `python3-tk`.

## Структура

- `AKG_2.py` — вся программа: расчет и интерфейс.
- `verify.py` — проверки модели и нового поведения, без дополнительных библиотек.
- `requirements.txt`, `.gitignore` — зависимости и исключения Python/PyCharm.
- `docs/ЛР2_Михайлов_Гришин_АКГ.docx` — актуальный отчет.
- `scenes/` — параметры пяти примеров в JSON.
- `results/` — исходный PNG и CSV; подпапки — дополнительные сцены; `additional_scenes.png` — сравнение для отчета.
