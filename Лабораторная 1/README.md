# АКГ · Лабораторная работа 1

**Тема:** расчёт освещённости плоскости от точечного источника света.
**Авторы:** Михайлов Пётр Сергеевич, Гришин Артём Евгеньевич, Р3311.
**Преподаватель:** доцент Потемин Игорь Станиславович.

Приложение рассчитывает освещённость в круговой области, показывает нормированную карту и сечения и сохраняет результат в PNG.

## Запуск

Необходим Python с Tkinter.

```bash
python -m pip install -r requirements.txt
python illumination_app.py
```

`illumination_app.py` содержит расчёт и графический интерфейс; `result_image.png` — пример результата; `ЛР1_Михайлов_Гришин_АКГ.docx` — отчёт.
